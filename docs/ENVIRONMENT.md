# ENVIRONMENT.md

Общие ограничения и правила окружения. Локальный `OPENCODE.md` может дополнять их
машинно-специфичными деталями, но не заменяет этот файл.

## Окружение
- Linux-контейнер, пользователь `coder` (без root/sudo).
- Node.js 24 / npm 11.
- Без графики и браузера: не вызывать `xdg-open` и не открывать окна.
- Python — только через `uv`, если действительно нужен.

## Процессы
- **Нельзя** `pkill -f node`, `pkill -9 node`, `killall node` — это убьёт OpenCode UI.
- Запуск бота в фоне:
  ```bash
  nohup node src/index.js > bot.log 2>&1 & echo $! > bot.pid
  ```
- Остановка по PID:
  ```bash
  [ -f bot.pid ] && kill $(cat bot.pid) && rm bot.pid
  ```
- Одновременно должен работать только один экземпляр бота (иначе Telegram 409 Conflict).

## Сеть и порты
- Порт `4096` занят OpenCode web UI: не биндить и не убивать процесс.
- Бот работает через исходящий long-polling (`polling: true`) и не требует входящих портов.
- Health-check (`server.js`) использует `PORT` (по умолчанию 3000).

## Файлы и секреты
- Рабочее пространство персистентно; артефакты хранить внутри проекта.
- `.env`, `credentials.json`, `bot.log`, `bot.pid` не коммитятся.
- Пакеты ставить только локально через `npm install`; `sudo`/`apt` недоступны.
