  - `amount` — inline-клавиатура `1–9`, `00`, `,`, `±`, `⌫`, `Сброс`, `✅ Готово`. Поддерживаются отрицательные суммы и до 2 знаков после запятой, ручной ввод оставлен fallback
  - `note` — ReplyKeyboard с кнопкой `❌ Отмена`, `one_time_keyboard: false` (коммит `c8e190a`)
  - `category`, `wallet` — ReplyKeyboard со списком + кнопкой `❌ Отмена`, поведение не менялось

  - Для `note` - обсудить что уместнее
- **Где смотреть:** `src/keyboards.js`, `src/calendar.js`, `src/amount.js`, `src/handlers/addHandler.js`, `src/handlers/callbackHandler.js`

## 3. Расхождения с исходным описанием
- **Точка входа**: в описании `src/index.js` называется точкой входа, но `start` = `node server.js`, `dev` = `nodemon src/index.js`. Фактически для прод-запуска используется `server.js` (импортирует `src/index.js`). `src/index.js` только логирует запуск.
- **main в package.json**: приведён в соответствие с `server.js`
- **cancelHandler**: обрабатывает `/cancel` и `❌ Отмена` **без** middleware доступа
- **balanceHandler/addHandler**: экспортируют `handleBalanceCommand`/`handleAddCommand`, используются из startHandler
- **README.md**: ранее пустой, теперь заполнен
- **logger**: минимальный консольный
- **Кнопки меню**: `(/add)`, `(/balance)` убраны из текста кнопок
- **Доступ**: `ALLOWED_USERS` обязателен, при пустом/отсутствии падает с ошибкой
- **TTL состояний**: добавлен 15 минут с уведомлением пользователя при истечении
