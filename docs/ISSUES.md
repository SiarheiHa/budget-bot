## 1. Найденные при ручном тесте

### 1.1 UX клавиатуры
- **Проблема:** на шаге `note` ReplyKeyboard сворачивается, пользователю приходится вручную разворачивать её/ставить курсор в поле ввода.
- **Текущее состояние:**
  - `date` — inline-календарь (навигация по месяцам, подписи `Пн–Вс`, `Сегодня`, `Вчера`, `❌ Отмена`), ручной ввод оставлен fallback
  - `amount` — inline-клавиатура `1–9`, `,`, `±`, `⌫`, `Сброс`, `✅ Готово`. Поддерживаются отрицательные суммы и до 2 знаков после запятой, ручной ввод оставлен fallback. Потеря цифр при быстрых нажатиях исправлена: `amountDraft` обновляется синхронно до `answerCallbackQuery`, рендер сериализован через `amountUi` (один in-flight запрос, debounce 1000 мс, повтор на 429). Осталось ограничение: при медленном вводе тап, попавший ровно в момент правки сообщения, Telegram-клиент может не отправить
  - `note` — ReplyKeyboard с кнопкой `❌ Отмена`, `one_time_keyboard: false` (коммит `c8e190a`)
  - `category`, `wallet` — ReplyKeyboard со списком + кнопкой `❌ Отмена`, поведение не менялось
- **Идеи для обсуждения:**
  - Для `note` - обсудить что уместнее
- **Где смотреть:** `src/keyboards.js`, `src/calendar.js`, `src/amount.js`, `src/amountUi.js`, `src/handlers/addHandler.js`, `src/handlers/callbackHandler.js`
- **Статус:** дата и сумма решены inline-клавиатурами; потеря цифр при быстром вводе суммы исправлена; остаточное ограничение при медленном вводе во время правки; шаг `note` на обсуждении

## 2. AI-парсинг

### 2.1 Ограничения MVP
- **Одна операция:** одна фраза — максимум одна транзакция. «Кофе 250 и такси 400» распознается как одна операция или не распознается.
- **Без переводов:** AI понимает только `Доход`/`Расход`; категории с типом `перевод` исключены из AI-флоу, для переводов остаётся `/add`.
- **Даты без года:** «3.10» трактуется как 3 октября текущего года; фразы вида «в прошлом году» не поддерживаются.
- **Свободный текст уходит в Cloudflare:** при включённом AI все не-командные сообщения отправляются в Workers AI. Если это нежелательно, `AI_PARSING_ENABLED=false`.
- **Лимит бесплатного тарифа:** 10 000 neurons/день; при исчерпании бот покажет `AI временно недоступен` и предложит `/add`.
- **Таймаут 10 секунд:** при медленном ответе модели бот не сохраняет запись и предлагает повторить или использовать `/add`.

### 2.2 Проверить на тестовом стенде
- [ ] Ложные срабатывания на обычных сообщениях (бот должен отвечать «не удалось распознать», а не молчать)
- [ ] Корректность дат: «сегодня», «вчера», «9 октября», «3.10»
- [ ] Неизвестная категория/кошелёк сразу открывают карточку с inline-выбором
- [ ] `Изменить` открывает карточку в том же сообщении; сумма, дата, категория, кошелёк и примечание редактируются
- [ ] Тип `Доход`/`Расход` берётся из `Categories!B` и меняется при смене категории
- [ ] Категории с типом `перевод` не предлагаются в AI-флоу
- [ ] Повторная отправка текста во время запроса не создаёт дубль

## 4. Расхождения с исходным описанием
- **Точка входа**: в описании `src/index.js` называется точкой входа, но `start` = `node server.js`, `dev` = `nodemon src/index.js`. Фактически для прод-запуска используется `server.js` (импортирует `src/index.js`). `src/index.js` только логирует запуск.
- **main в package.json**: приведён в соответствие с `server.js`
- **cancelHandler**: обрабатывает `/cancel` и `❌ Отмена` **без** middleware доступа
- **balanceHandler/addHandler**: экспортируют `handleBalanceCommand`/`handleAddCommand`, используются из startHandler
- **README.md**: ранее пустой, теперь заполнен
- **logger**: минимальный консольный
- **Кнопки меню**: `(/add)`, `(/balance)` убраны из текста кнопок
- **Доступ**: `ALLOWED_USERS` обязателен, при пустом/отсутствии падает с ошибкой
- **TTL состояний**: добавлен 15 минут с уведомлением пользователя при истечении
